# Semantic Technologies: RDF/XML and OWL Ontology

Coursework project demonstrating semantic-web technologies through RDF/RDFS modelling, RDF/XML serialisation, Apache Jena, and OWL ontology engineering.

## Overview

This repository contains selected coursework from the Semantic Technologies course at the University of Trier. It demonstrates the creation of machine-readable knowledge models and semantic relations using Java, Apache Jena, RDF/RDFS, RDF/XML, and OWL.

## Technologies

- Java
- Apache Jena
- RDF and RDFS
- RDF/XML serialisation
- OWL ontology modelling
- Protégé / OntoGraf

## Contents

### Assignment 1: RDF and RDFS with Apache Jena

- **Exercise 1:** Creates an RDF model for course-related entities and exports it as RDF/XML.
- **Exercise 2:** Implements an airline domain model with airlines, airports, flight connections, customers, trips, and flights. The model uses RDF/RDFS concepts and is serialised as RDF/XML.

### Assignment 2: OWL Sandwich Ontology

An OWL ontology modelling sandwiches and their ingredients. It includes classes, object properties, inverse properties, disjointness, cardinality restrictions, and semantic constraints.
